Публикация на GitHub и сборка APK

Приложение полностью автономно в одном файле index.html. Все данные надежно хранятся на устройстве.

Шаг 1. Выкладываем на GitHub Pages

  1. Создайте публичный репозиторий на github.com (например, pvz-shifts-pro).
  2. Загрузите этот файл под именем index.html.
  3. В настройках репозитория откройте Settings → Pages, выберите ветку main и нажмите Save.

Шаг 2. Конвертируем в Android .APK

  1. Перейдите на бесплатный сервис pwabuilder.com или webintoapp.com.
  2. Вставьте ссылку на ваш GitHub Pages.
  3. Скачайте готовый установочный файл .apk и прикрепите его в раздел Releases вашего GitHub!
